# Catalog images

The 25 local images match the paths in `API/Data/DBInitializer.cs` and are served
by Vite from `/images/products/`. No external image requests are needed at runtime.
`sources.json` records each image's original file page, creator, and license.
Consult those source pages for the full attribution and reuse terms.

These are demo catalog images. Some show related models, generations, sizes, or
colors rather than the precise SKU in the catalog: Xiaomi, Dell XPS, ASUS ROG,
Sony headphones, Galaxy Buds, Galaxy Watch, iPad, LG and Dell monitors, Razer
keyboard, and PlayStation. Replace those files with verified SKU photography
before using the catalog as a real store.

`placeholder.svg` is a local fallback used when a product image is missing.
